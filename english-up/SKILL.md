# English up · 一年制英语能力提升系统

把「制定计划 → 每日推送 → 提交作业 → 标注讲解 → 批改 → 记录 → 周复盘」做成一个可长期运行的闭环。核心不是给一份计划表，而是**每天产出可执行的任务并把学习数据落进文件**。

## 何时使用

- 用户想制定 **数周到一年** 的英语学习计划，或想把学习变成「每天自动推送的任务」
- 用户想要 **每日阅读材料 + 生词/语法讲解**、**作文批改**、**口语陪练**、**背单词/精听/精读打卡**
- 用户在为 **四六级 / 雅思 / 托福 / 考研英语** 等考试做准备，需要阶段化路线
- 用户已有学习系统，需要**接管、调整难度、统计进度或生成周报**

## 工作流（按顺序执行）

### 1. 先采集 8 个参数

| 参数 | 说明 |
|---|---|
| 当前水平 | CEFR 或自评（A2/B1/B2…） |
| 一年目标 | 现实可达：如 B1→C1；不要承诺「母语者级别」 |
| 目标考试与分数、考试日期 | 无则写「无」 |
| 每晚可用时间 | 分钟 |
| 学习地点与开始时间 | 如 18:00–18:30 到图书馆 |
| 环境限制 | 能否出声、能否录音、有无网络 |
| 词汇 App | 用户已有的工具（Anki/墨墨/不背单词…） |
| 工作目录 | 文件落地路径 |

若用户没有明确说，**直接问**，不要假设。目标定得过于激进时要**先说清现实边界**（例如：真正的母语者水平一年内不可达，可量化的替代目标是 C1 + 具体行为指标）。

### 2. 生成四类文件

1. **一年冲刺计划.md**：四阶段路线图 + 52 周主题表 + 每日两段式模板 + 材料清单 + KPI + 里程碑 + 断更规则 → 用 `references/year-plan-template.md`
2. **每日打卡表.xlsx**：用 `scripts/build_tracker.py` 生成（打卡表 / 周汇总 / 指标看板 / 资源清单，含 SUMIF 与完成率公式）
3. **口语录音日志.md**：开口恐惧阶梯 + 基线 + 每月复录 → 用 `references/speaking-ladder.md`
4. **写作批改记录.md**：批改台账 → 用 `references/writing-log-template.md`
5. **每日记录/** 目录：每天一个 `YYYY-MM-DD_WNDN.md` → 用 `assets/daily-record-template.md`

文件结构见 `references/system-prompt.md` 第九节。

### 3. 每日推送（写文件，聊天只给增量）

先读「上一份当日总结」的《明日难度调整》，再决定今天的难度；然后把当天内容**直接写进** `每日记录/YYYY-MM-DD_WNDN.md`：

- 📖 今日阅读：**250–300 词原创英文文章**（难度按阶段递增），文内**加粗 6 个地道语块**
- ✍️ 三个任务：3 道理解题（英文作答）/ 6 个语块各造 1 句 / 指定 1 段做影子跟读
- 📝 今日写作：80–150 词，要求用上文中 3 个语块
- 🕕 时间线（A 段静音 + B 段出声）

文章**必须原创**，不整段搬运外部文本（需要题材灵感可用搜索，但不要复制正文）。

### 4. 收到作业后（闭环）

用户会提交：**不会的单词/语法点清单 + 理解题答案 + 作文**。依次完成：

1. **把原文再输出一遍**，用【1】【2】… 把用户列的点**标在原文对应位置**
2. **逐条解释**：意思 / 用法要点 / 例句 / 常见坑（语法点讲清规则）
3. **判定理解题**：给更好的标准写法，重点看「是否写成完整正确的句子」
4. **作文批改固定三项**：① 中式表达 → 地道替换（表格）② 语法/搭配硬伤 ③ 3 个可升级句（只给方向，让用户自己重写第 2 稿）+ CEFR 估计 + 考试作文折算分
5. **写当日总结 md**：打卡数据、标注版原文、逐条讲解、批改、**明日难度调整**、待办
6. **更新数据表**：打卡表当日行、写作台账、指标看板

文章/讲解/批改全部落文件，聊天只回 ≤5 行（文件路径 / 分数 / 最关键的 2 条错误 / 待办 / 追问）。

### 5. 动态难度调节

| 用户表现 | 次日调整 |
|---|---|
| 理解题全对、作文 ≥ 目标分 | 文章 +50 词、升半档；写作改议论文 |
| 基础语法错密集 | 降半档、缩短句长；次日复现前一天 3 个语块；写作加硬性语法要求 |
| 中式直译 ≥5 处 | 次日文章刻意多埋对应地道表达，批改做「中文→英文」对照 |
| 某语块反复错 | 连续 3 天在文章里复现，直到能自己造句 |
| 精听/口语连续 2 天未打卡 | 置顶红线警告并下调难度，先恢复习惯 |

### 6. 周复盘与里程碑

每周日：统计打卡天数/时长/完成率 → 最弱板块 → 下周 3 条可执行调整 + 难度基调，**写进** `每日记录/YYYY-MM-DD_周复盘_WNN.md`，聊天只给 5 行。
每月最后一个周日：同题复录口语，只记 4 个数（卡顿 / 填充词 / 语速 wpm / 中文替代词数）。
每 8 周：阶段测评（词汇量 / 无字幕听力 / 口语录音对比 / 真题）。

## 红线（必须在计划与提醒里写明）

1. **每天必须有一段出声的英语**——图书馆负责输入+写，家和路上负责输出；**录音不是红线，出声才是**
2. 绝不出现零打卡日：最小版 = 词汇 10′ + 出声 2′
3. 背单词 App 待复习 >120 张时，当天不加新词（防队列雪崩）
4. 作文必须自己重写第 2 稿；打卡必须诚实，不虚报分钟数
5. 每天必须有输出（口语或作文至少一项）

## 生成打卡表

```bash
python scripts/build_tracker.py \
  --out "每日打卡表.xlsx" \
  --start 2026-10-19 \
  --weeks 52 \
  --prep-days 4 \
  --app "不背单词" \
  --exam-name "CET-6" \
  --daily-min 150
```

只依赖 `openpyxl`。生成后**必须重算校验**：用 LibreOffice Kit 的 `recalculate`（若可用）或让用户首次在 Excel 打开时刷新，并核对某个工作日的合计/完成率与周汇总 SUMIF 是否等于手算值。

## 环境适配

- **有定时提醒能力**：把「每日推送」设成每天固定时间（在用户开始学习前 20–30 分钟）、「周复盘」设成每周日学习结束后
- **没有定时能力**：告诉用户每天发一句「今日」，你按第 3 步产出
- **无法抓取网页**：文章一律原创；不要因为抓不到新闻就中断流程
- **环境不能出声/录音**：启用 `references/speaking-ladder.md` 的 L1–L2 阶段（对口型跟读、耳语），不要因此砍掉口语板块
