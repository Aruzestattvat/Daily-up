### 一句实话
严格的「母语者水平」需要 5–10 年高强度沉浸，一年内不可达。但可以拆成 6 个可训练指标，一年内大幅逼近：
**自动化 / 语块化 / 韵律（连读弱读语调）/ 英语思维 / 理解容错 / 表达耐力**。计划按这 6 项设计。

### 工作量核账

## 三、每日两段式模板

> 原则：**能安静做的放图书馆/自习室，必须出声的放家里和路上。**
> A 段到点（{{到馆时间}}）**放下包就开始第一项**，不要先刷手机、不要临时挑材料。

### A 段｜静音版（约 125 分钟）

| 时段 | 时长 | 板块 | 做法 |
|---|---|---|---|
| +0′ | 20′ | 词汇 | {{词汇 App}}：先清「待复习」（跟读例句，不默看）→ 15–20 新词；>120 张不加新词；安静环境用气声/对口型 |
| +20′ | 35′ | 精听 | 戴耳机听写 1–2 分钟材料 → 对原文 → 圈出连读/弱读（影子跟读留到 B 段） |
| +55′ | 10′ | 休息 | 离座、不碰手机 |
| +65′ | 30′ | 阅读 | 读当日推送文章 + 3 个任务 |
| +95′ | 20′ | 写作 | 写当日题目，用上文中 3 个语块 |
| +115′ | 10′ | 复盘打卡 | 错词本/语块本 + 打卡表登记 |

### B 段｜出声版（约 35 分钟，离馆后）

| 时机 | 时长 | 做什么 |
|---|---|---|
| 路上 | 10–15′ | 影子跟读当晚精听材料（1.5 倍速 → 原速，出声 5 遍） |
| 到家 | 10′ | 不看稿复述当晚精听/阅读内容 |
| 到家 | 10′ | 即兴说当日话题（录音与否按《口语录音日志》当前阶梯阶段） |
| 到家 | 5′ | 回听计数（录音阶段） |

> 晚归最小版（到家晚于 {{晚归阈值}}）：路上跟读 10′ + 出声 2′，30 分钟内收工。**可以缩短，不能归零。**

### 一周节奏
| 星期 | 侧重 |
|---|---|
| 周一 | 精听为王 |
| 周二 | 阅读为王 |
| 周三 | 口语为王（B 段加量） |
| 周四 | 写作为王（观点段 + 论证） |

| 周日 | 复盘日 1.5–2 h：每周产出入库 + 轻量输入 |

### 每周固定产出（周日交付）
1. 1 篇 200 词长文（写进《写作批改记录》）
2. 口语：按《口语录音日志》阶梯阶段执行，每月最后一个周日复录同题
3. 20 个新语块入本
4. 打卡表周汇总刷新

### 断更规则
- 绝不出现零打卡日：最小版 = 词汇 10′ + 出声 2′
- 连续断 2 天 → 次日 30 分钟「重启版」+ 3 行复盘，不补昨天的量
- 每周允许 1 天降到最小版，但打卡必须诚实

## 五、材料与工具清单

### 词汇
- 主 App：{{词汇 App}}（选一本词书，P1–P3 只用这一本）
- 设置：每日新词 20（冲刺期降到 10）；每天先清待复习；开启例句原声/拼写
- 防积压：待复习 >120 张 → 当天不加新词

### 听力 / 口语
- 入门：BBC Learning English – 6 Minute English
- 进阶：TED / TED-Ed、BBC Global News Podcast、The Daily
- 影子跟读：TED 演讲、生活类美剧片段（不要中文字幕）
- 发音：《American Accent Training》+ YouGlish
- 口语实战：AI 语音对话每天 10 分钟；外教每周 1–2 次（P1 后半段开始）

### 阅读
- 每日推送的原创文章（250–300 词 + 6 语块）为主
- 加量：The Economist / Guardian / New Scientist + 原版书（*Atomic Habits* → *Sapiens* → *Educated*）

### 写作
- 每日 80–150 词（推送题目），周日 200 词长文
- 批改三项：中式表达 → 地道替换 / 语法搭配硬伤 / 3 个可升级句
- 改完**必须自己重写第 2 稿**

### 语法
- 《English Grammar in Use》：中级 → 高级，每周 2 单元，做题别只看讲解

### 考试专用
- 近 10 年真题（≥3 刷）、听力专项、翻译专项（中国特色表达）
- 报名与考试信息以官方通知为准

## 七、每日闭环流程与文件结构

### 四步闭环
1. 学习前收到推送：当日文章 + 三个任务 + 写作题 + 时间线
2. 晚上学：A 段静音 → B 段出声
3. 提交：生词/语法清单 + 理解题答案 + 作文稿
4. 收到三样东西：**标注版原文 + 批改 + 当日总结 md**，并自动更新打卡表与写作台账

### 输出规则（省 token）
**文件优先，聊天只给增量**：文章、标注、讲解、批改、总结、周报全部写进文件；聊天只输出 ① 文件路径 ② 结论/分数 ③ 追问或红线警告 ④ 新待办，**单次 ≤5 行**。

### 动态难度调节
| 表现 | 次日调整 |
|---|---|
| 理解题全对、写作高分 | 文章 +50 词、升半档；写作改议论文 |
| 基础语法错密集 | 降半档、缩短句长；复现前一天 3 个语块；写作加硬性语法要求 |
| 中式直译 ≥5 处 | 次日文章多埋对应地道表达；批改做「中文→英文」对照 |
| 某语块反复错 | 连续 3 天复现，直到能自己造句 |
| 精听/口语连续 2 天未打卡 | 置顶红线警告 + 下调难度，先恢复习惯 |

## 八、红线
1. 每天必须有一段**出声**的英语（录音不是红线，出声才是）
2. 绝不零打卡：最小版 = 词汇 10′ + 出声 2′
3. 待复习 >120 张不加新词
4. 作文必须自己重写第 2 稿；打卡诚实
5. 每天必须有输出（口语或作文至少一项）
